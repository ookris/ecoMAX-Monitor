Wymagania

  • Python 3.8+
  • Modul Elfin EW11A skonfigurowany jako serwer TCP (domyslnie port 8899)
  • Sterownik ecoMAX podlaczony do EW11A przez RS485 (port G2, wtyczka RJ11)
  • VM lub komputer z dostepem do sieci, w ktorej jest EW11A

Instalacja

1. Pobranie kodu

git clone https://github.com/<twoj-repo>/SerialToWiFI_Elfin-EW11A.git
cd SerialToWiFI_Elfin-EW11A/app

2. Srodowisko wirtualne (zalecane)

python3 -m venv venv
source venv/bin/activate

3. Instalacja zaleznosci

pip install -r requirements.txt

4. Utworzenie katalogu na baze danych

mkdir -p data

Konfiguracja

Plik config.py

Edytuj plik config.py i ustaw adres IP modulu EW11A:

# Elfin EW11A - polaczenie TCP
EW11A_HOST = "192.168.1.100"  # <-- zmien na IP twojego EW11A
EW11A_PORT = 8899             # Port TCP (domyslny dla EW11A)

# Interwaly
READ_INTERVAL = 5             # Odczyt danych co X sekund
DB_SAVE_INTERVAL = 60         # Zapis do bazy co X sekund
DB_RETENTION_DAYS = 30        # Przechowywanie historii (dni)

# Serwer WWW
FLASK_HOST = "0.0.0.0"       # 0.0.0.0 = dostepny z kazdego IP
FLASK_PORT = 5050             # Port dashboardu

# Baza danych
DB_PATH = "data/measurements.db"

Konfiguracja Elfin EW11A

Modul EW11A musi byc skonfigurowany w trybie TCP Server:

ParametrWartosc
Baud rate115200
Data bits8
ParityNone
Stop bits1
TCP port8899 (domyslny)

Konfiguracja odbywa sie przez panel webowy EW11A (domyslnie http://10.10.100.254) lub aplikacje mobilna. Szczegoly w dokumentacji w katalogu EW11A manual/.

Sprawdzenie polaczenia z EW11A

Przed uruchomieniem aplikacji mozna sprawdzic czy EW11A odpowiada:

# Sprawdz czy port jest otwarty
nc -zv 192.168.1.100 8899

# Podglad surowych danych (Ctrl+C aby zakonczyc)
nc 192.168.1.100 8899 | xxd | head -50

Jesli widzisz dane binarne — polaczenie dziala.

Autostart przy starcie systemu (systemd)

Aby aplikacja uruchamiala sie automatycznie po restarcie VM:

1. Utworz plik uslugi systemd

sudo nano /etc/systemd/system/ecomax-monitor.service

Wklej ponizszą zawartosc (dostosuj sciezki do swojej instalacji):

[Unit]
Description=ecoMAX Monitor - odczyt danych ze sterownika pieca
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ookris
Group=ookris
WorkingDirectory=/home/ookris/SerialToWiFI_Elfin-EW11A/app
Environment="PATH=/home/ookris/SerialToWiFI_Elfin-EW11A/app/venv/bin:/usr/bin"
ExecStart=/home/ookris/SerialToWiFI_Elfin-EW11A/app/venv/bin/python run.py
Restart=always
RestartSec=10

# Logi
StandardOutput=journal
StandardError=journal
SyslogIdentifier=ecomax-monitor

[Install]
WantedBy=multi-user.target
Uwaga: Zmien User, Group, WorkingDirectory i ExecStart na sciezki odpowiadajace twojej instalacji. Jesli uzywasz innego IP EW11A niz ten w config.py, dodaj argumenty:
ExecStart=/.../venv/bin/python run.py --host 192.168.0.50

2. Aktywuj i uruchom usluge

# Przeladuj konfiguracje systemd
sudo systemctl daemon-reload

# Wlacz autostart
sudo systemctl enable ecomax-monitor

# Uruchom teraz
sudo systemctl start ecomax-monitor

3. Zarzadzanie usluga

PolecenieOpis
sudo systemctl status ecomax-monitorSprawdz status
sudo journalctl -u ecomax-monitor -fPodglad logow (na zywo)
sudo journalctl -u ecomax-monitor -n 50Ostatnie 50 linii logow
sudo systemctl restart ecomax-monitorRestart
sudo systemctl stop ecomax-monitorZatrzymanie
sudo systemctl disable ecomax-monitorWylacz autostart

Protokol komunikacji

Aplikacja obsluguje dwa tryby parsowania danych:

Tryb 1: PoC (pasywny nasluch)

  • Sterownik cyklicznie wysyla paczki 361-bajtowe z headerem 0x68 0x69 0x01
  • Dane sa na stalych offsetach (float32 little-endian)
  • Prostszy, pewniejszy — wystarczy nasluchiwac

Tryb 2: EcoNET (pelny protokol)

  • Format ramki: [0x68][Dlugosc:2 LE][DA][SA][Typ][Ver:0x05][Payload][CRC XOR][0x16]
  • Ramka FRAME_DATA_ANS (0x35) zawiera wszystkie biezace dane
  • Wymaga odpowiadania ramka B0 (device available)
  • Wiecej danych (tryb pracy, stany pomp, alarmy)
Autodetect: Aplikacja automatycznie probuje oba formaty i uzywa tego, ktory znajdzie w strumieniu danych.

Rozwiazywanie problemow

Aplikacja nie laczy sie z EW11A

  1. Sprawdz czy EW11A jest w sieci: ping 192.168.1.100
  2. Sprawdz port: nc -zv 192.168.1.100 8899
  3. Sprawdz logi: sudo journalctl -u ecomax-monitor -n 20
  4. Sprawdz konfiguracje EW11A (tryb TCP Server, port 8899, baud 115200)

Dashboard pokazuje "Rozlaczony"

  • Aplikacja automatycznie probuje reconnect co kilka sekund
  • Sprawdz logi — moze byc problem z siecia lub EW11A

Brak danych na wykresie

  • Dane sa zapisywane do bazy co 60 sekund (konfigurowalne w config.py)
  • Poczekaj minute po uruchomieniu i odswiez strone

Port 5050 jest zajety

python run.py --web-port 8080

Lub zmien FLASK_PORT w config.py.
